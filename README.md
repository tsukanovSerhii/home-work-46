# 🚀 Redux Toolkit Async Project

Рефакторинг існуючого проекту для підтримки асинхронних дій за допомогою **Redux Thunk**.

## ✨ Реалізовані вимоги
- Проект ініціалізовано на базі Vite + React + TypeScript.
- Налаштовано **Redux Toolkit** (`configureStore`, `createSlice`).
- Додано асинхронну дію через `createAsyncThunk` для отримання списку користувачів з API (JSONPlaceholder).
- Оброблено всі можливі стани: `pending` (завантаження), `fulfilled` (успіх), `rejected` (помилка).
- Використовуються типізовані хуки `useAppDispatch` та `useAppSelector`.
- Інтерфейс стилізовано за допомогою Tailwind CSS v4.

## 📦 Встановлення та запуск

1. Клонувати репозиторій:
   ```bash
   git clone <ВАШЕ ПОСИЛАННЯ>
   cd home-work-46
   ```

2. Встановити залежності:
   ```bash
   npm install
   ```

3. Запустити локально:
   ```bash
   npm run dev
   ```
